Cobalt Tools — self-hosted media downloader, no watermarks, no ads

A complete self-hosted cobalt deployment (API + web UI) for downloading from YouTube, TikTok, Twitter/X, Instagram, and 20+ other platforms. Both services run the official images unmodified; this template adds the real healthcheck the official Railway template ships without, and documents the web service's on-boot build step (confirmed live: ~11-13s) with a healthcheck timeout sized for it.
